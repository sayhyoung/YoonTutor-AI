# 윤선생 AI 전화관리 — call-review

기존 `web` 프로젝트를 변경하지 않고 별도로 검증하는 모바일 앱/교사용 웹 프로젝트다.

## 구성

- `apps/mobile`: Android/iOS용 Expo·React Native 앱
- `apps/teacher-web`: 기존 교사 LMS에서 링크로 여는 Next.js 관리 페이지
- `packages/shared`: 통화 단계, 학습 계획, 리포트 등 공통 도메인 타입

## 현재 범위

첫 버전은 프리뷰 데이터로 다음 흐름을 검증한다.

1. 다음 관리 전화 확인
2. 전화 수신
3. 취약 표현 음성 또는 텍스트 복습
4. 복습 표현을 활용한 짧은 대화
5. 통화 결과와 다음 관리 안내

음성 사용이 어려운 상황을 위해 모든 학습 단계에서 자막과 텍스트 입력을 제공한다.

짧은 대화에서는 AI가 당일 복습 표현을 포함한 질문을 영어로 제시한다. 학습자의 답변에 맞춰 최대 두 번 후속 질문을 이어가며, 말하기가 어려우면 화면의 영어 답변 선택지를 사용할 수 있다. 학습자가 종료를 선택하거나 20초 동안 응답하지 않으면 통화를 자연스럽게 마친다.

학습자 마이페이지에서는 교사가 정한 전화 일정과 이전 전화관리 학습이력을 확인한다. 전화 요일·시간·주당 빈도는 교사용 관리 페이지에서 설정하며, 초기 정책상 학습자는 읽기 전용으로 제공한다.

## 실행

```bash
npm install
npm run dev:mobile
npm run dev:teacher
```

교사용 웹은 기본적으로 `http://localhost:3100`에서 실행한다.
