# 베플리 AI 전화관리 앱 로고

베플리의 갈색 곰 귀 후드, 노란 앞머리, 볼터치와 통화용 헤드셋을 작은 화면에서도 구분되는 벡터 형태로 단순화한 로고입니다. 이미지 안에는 글자를 넣지 않았습니다.

## 핵심 파일

- `icon-master.svg`, `icon-master-1024.png`: 편집·확장용 마스터
- `ios-icon-1024.png`: iOS 앱 아이콘. 1024×1024 RGB, 투명도 없음
- `android-adaptive-foreground.png`: Android 적응형 아이콘 전경. 1024×1024 RGBA
- `android-adaptive-background.png`: Android 배경. 1024×1024 RGB, `#12151C`
- `android-monochrome.png`: Android 13+ 테마 아이콘용 흰색 실루엣
- `notification-icon.png`: 96×96 흰색 단색 알림 아이콘
- `splash-icon.png`, `splash-icon-dark.png`: 시작 화면용 투명 이미지
- `web-favicon.png`: Expo web용 48×48
- `favicon.ico`: 16·32·48px 크기를 포함한 교사 웹 파비콘
- `icon.svg`, `apple-icon.png`: 교사 웹용
- `play-store-icon-512.png`, `play-feature-graphic.png`: Google Play용

선택 파일로 iOS 다크·색조 아이콘 및 웹 매니페스트 아이콘도 포함했습니다. `preview.png`에서 여러 크기와 배경색을 확인할 수 있습니다.

## 색상

- Android 아이콘 배경: `#12151C`
- 알림 강조색: `#7B4A2E`
- 스플래시 밝은 배경: `#F6F3EE`
- 스플래시 어두운 배경: `#12151C`

현재 앱 설정의 적응형 아이콘 배경색은 `#171522`입니다. 이 에셋을 앱에 적용할 때 `#12151C`로 맞추면 Android 아이콘 배경이 정확히 일치합니다.

이 패키지는 이미지 에셋입니다. 앱 설정과 저장소 파일은 변경하지 않았습니다. 교사 웹 파비콘은 기존 LMS 파비콘과의 사용 방침이 정해진 뒤 적용하면 됩니다.
