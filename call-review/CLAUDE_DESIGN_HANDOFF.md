# Claude Design 핸드오프 — 윤선생 AI 전화관리 학습자 앱

## 요청 목적

현재 `call-review` 모바일 앱의 UI를 처음부터 다시 디자인한다. **전화가 걸려와 코코 선생님과 짧게 영어를 복습하는 경험**이 먼저 느껴져야 한다. 기존 화면의 색상·카드 모양·배치를 답으로 여기지 말고, 아래 제품 흐름과 학습 원칙을 유지하면서 더 세련되고 친근한 모바일 앱 디자인을 제안해 달라.

이번 디자인 대상은 **학습자용 Android/iOS 앱**이다. 교사용 관리 웹은 별도 과제이며 이번 화면 설계에 포함하지 않는다. 구현·배포는 이 핸드오프의 범위가 아니다.

## 제품 맥락과 사용자

- 제품명: **윤선생 AI 전화관리**. AI 선생님 캐릭터 이름은 **코코**.
- 주요 사용자: 윤선생 영어 학습자. 성인 전화영어 앱을 그대로 복제하지 말고, 어린/청소년 학습자도 부담 없이 이해할 수 있는 명료한 인터페이스가 필요하다.
- 학습 데이터: 기존 학습에서 틀린 **단어와 문장**을 전화 복습 계획으로 가져온다. **평가 결과는 대상에서 제외**한다.
- 기본 통화: 대략 3개 표현을 짧게 복습한 뒤, 그날 표현을 활용한 영어 질문에 답하는 짧은 대화(첫 질문 + 최대 2회 후속 질문).
- 전화 요일·시간·주당 빈도는 **교사가 설정**한다. 학습자는 마이페이지에서 일정을 읽기만 하며 직접 수정하지 않는다.
- 현재 앱은 프리뷰 단계다. 실제 녹음/STT/TTS, AI 생성 질문, 푸시, 결과 저장 등은 아직 완성 기능처럼 디자인하거나 문구로 약속하지 말 것. 다만 향후 실제 기능이 붙어도 성립하는 UI 구조로 설계한다.

## 반드시 지킬 경험 원칙

1. **전화 경험이 먼저, 학습 도구는 그 안에.** 일반 문제풀이 앱이나 복잡한 LMS 대시보드처럼 보이지 않게 한다.
2. **통화 중 기본 테마는 밝고 개방감 있게.** 이전의 거의 검은 전체 배경은 답답하다는 피드백이 있었다. 다크 모드를 사용자가 선택하면 어두운 통화 화면으로 전환할 수 있게 한다. 밝은 모드를 기본값으로 표현한다.
3. **말할 수 없어도 학습 가능.** 음성/텍스트 전환과 읽을 수 있는 자막·한국어 뜻을 눈에 띄되 과하지 않게 제공한다.
4. **복습과 대화의 과제를 혼동시키지 않는다.** 복습은 제시된 한국어 표현을 영어로 말하거나 입력한다. 마지막 대화는 **코코가 영어로 질문하고 학습자가 영어로 답한다**. 코코 질문 아래의 한국어는 자연스러운 *질문의 뜻*이지 영작 과제가 아니다.
5. **실패 부담을 낮춘다.** 대화 구간은 정오답 표시를 하지 않는다. 짧은 답도 허용하고, 어려우면 영어 답변 선택지를 열 수 있으며, 원할 때 종료할 수 있다.
6. 힌트는 기존에 채택한 것처럼 **독립된 패널**로 펼쳐 보여준다. 문제 본문이나 대화 질문과 섞지 않는다.
7. 시각적 즐거움은 필요하지만 과도한 게임 장식·점수 압박·애니메이션으로 통화를 방해하지 않는다.

## 설계할 화면과 상태

| 화면 | 핵심 정보·행동 | 추가로 보여줄 상태 |
|---|---|---|
| 홈 | 다음 관리 전화, 오늘 복습할 단어·문장 수, `지금 전화받기`, 마이페이지 진입 | 통화 준비/예정 안내 |
| 전화 수신 | 코코 선생님, 전화받기/나중에, 통화 기대감 | 밝은 기본형과 다크형 |
| 연결 중 | 연결·마이크 준비 피드백 | 짧고 안정적인 전환 상태 |
| 통화—표현 복습 | 현재 표현, 진행도(예: 1/3), 코코의 안내, 영어로 답하기, 힌트, 통화 종료 | 음성 대기/듣는 중/인식 결과 확인, 텍스트 입력, 힌트 열림 |
| 통화—짧은 대화 | **코코의 영어 질문 → 한국어 뜻 → 내가 영어로 답할 차례**라는 명확한 위계 | 답변 선택지 열림, 지난 내 답변, 무응답 안내, 종료 |
| 결과 | 복습한 표현 수, 다시 볼 표현 수, 코코의 격려, 사용한 표현, 홈 복귀 | 정상 완료/직접 종료/무응답 종료에 맞는 톤 |
| 마이페이지 | 교사가 설정한 전화 일정, 이전 전화관리 학습이력 | 일정 읽기 전용·변경은 교사에게 요청 |

통화 화면 상단에는 코코/진행 상태를 알아볼 수 있어야 한다. 힌트, 한국어 뜻 표시, 밝기/다크 전환을 제공하되 작은 화면에서 아이콘이 밀집하거나 의미가 불명확해지지 않도록 재구성해도 된다. 통화 중 가장 중요한 답변 행동은 엄지가 닿기 쉬운 위치에 둔다.

## 문구·상호작용 기준

- 복습 프롬프트 예: `오늘의 복습 표현` → `나는 오늘 숙제가 있어.` → `영어로 말해 볼까요?`
- 대화 프롬프트 예: `코코의 질문` → `Do you have homework from school today?` → `오늘 학교 숙제가 있니?` → `이제 영어로 대답해요`.
- `한국어 뜻`을 끄더라도 코코의 **영어 질문은 항상 남는다**.
- 대화 응답이 어려우면 `대답이 어려워`를 눌러 영어 답변 선택지를 펼친다. 선택지는 영어 답과 한국어 뜻을 함께 보여줄 수 있다.
- 음성 인식 결과는 곧바로 제출한 것으로 처리하지 않는다. `이렇게 들었어` 확인 후 전송하거나 다시 말할 수 있어야 한다.
- 대화 중 `오늘은 여기까지`로 종료할 수 있고, 응답이 없으면 20초 후 마친다는 안내가 필요하다. 시간 안내가 겁주거나 재촉하는 느낌이 들지 않게 한다.
- 성공/오답 피드백은 복습 단계에만 해당한다. 대화에서는 자연스러운 후속 질문과 통화 후 요약을 사용한다.

## 비주얼 방향과 제약

- 제안할 톤: **따뜻하고 믿음직한 선생님 + 가벼운 전화 통화의 리듬**. 유아용 캐릭터 앱처럼 보이거나 성인용 콜센터 UI처럼 차갑지 않게 균형을 잡는다.
- 밝은 기본형은 넓은 여백, 읽기 쉬운 대비, 절제된 강조색을 사용한다. 다크형은 단순 반전이 아니라 같은 위계를 유지한 별도 화면으로 설계한다.
- 코코의 아바타/상징을 제안할 수 있다. 단, 현재 앱의 `코` 원형 아바타는 임시 표시이므로 그대로 따를 필요가 없다. 새 브랜드 캐릭터가 필수 산출물은 아니다.
- 320px급 작은 폰부터 최신 iPhone/Android 화면까지 고려한다. 긴 영어 질문, 한국어 뜻, 키보드가 열린 상태, 안전 영역, 스크롤과 고정 입력부가 함께 있는 상태를 확인한다.
- 터치 목표는 충분히 크게, 텍스트 대비는 접근성 수준으로, 색상만으로 상태를 전달하지 않도록 한다. 자막/의미 표시와 음성 상태는 접근성 레이블도 설계한다.
- `heyring_img/`의 헤이링 참고 이미지는 **전화 경험의 참고 자료**일 뿐 복제 대상이 아니다. 윤선생 사용자·학습 목표에 맞춰 독자적인 화면 언어로 재해석한다.

## 요청 산출물

1. 서로 다른 콘셉트 2안의 간단한 방향 제시(무드, 색·타이포, 통화 화면의 차이)와 최종 추천 근거.
2. 추천안의 주요 화면 전체에 대한 **편집 가능한 고충실도 모바일 시안**. 특히 `통화—표현 복습`과 `통화—짧은 대화`는 음성/텍스트, 힌트/선택지, 밝은/다크 상태를 볼 수 있게 한다.
3. 재사용 가능한 디자인 토큰(색상·타이포·간격·모서리·그림자), 컴포넌트 상태(기본/누름/비활성/듣는 중/오류), 아이콘·일러스트 에셋 목록.
4. 화면 간 이동과 상태 전환을 표시한 간단한 플로우, 구현자가 판단해야 할 미확정 사항 목록.
5. 개발 전달용 각 화면의 레이아웃/간격/반응형 규칙. 가능하면 320×568, 375×812, 390×844 크기에서 핵심 화면을 확인한다.

**우선순위:** 먼저 통화 화면(복습·짧은 대화)의 정보 위계와 밝은 기본형을 검증한 뒤, 같은 시스템으로 수신·홈·결과·마이페이지를 확장한다. 디자인이 완성되기 전에는 앱 전체 코드에 일괄 적용하지 않는다.

## 현재 구현 참고 위치

- 모바일 화면·문구: `call-review/apps/mobile/App.tsx`
- 색상·간격·모서리·폰트 토큰: `call-review/apps/mobile/src/theme.ts`
- 통화 상태와 동작: `call-review/apps/mobile/src/useCallSession.ts`
- 제품 흐름: `call-review/README.md`, `call-review/ARCHITECTURE.md`
- 통화 앱 참고 이미지: `heyring_img/`
- 현재 로컬 프리뷰: `http://localhost:8082/` (서버가 실행 중일 때만)

현재 구현은 **기능과 문구의 참고 자료**다. 현재의 디자인 디테일, 임시 타이머 표시, 임시 음성 동작을 그대로 재현할 필요는 없다. 코드·이미지·시안에 실제 학습자의 개인정보나 인증정보를 포함하지 않는다.
